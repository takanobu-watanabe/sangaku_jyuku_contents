# タングラムパズル集（標準7ピース）

## ピース定義

標準タングラムの7ピース（整数グリッド、4×4正方形ベース）:

```
0: 大三角形A   [[0,0],[4,0],[2,2]]              面積=4  直角二等辺三角形(直角at(2,2))
1: 大三角形B   [[0,0],[4,0],[2,2]]              面積=4  直角二等辺三角形(直角at(2,2))
2: 中三角形    [[0,0],[2,0],[0,2]]              面積=2  直角二等辺三角形(直角at(0,0))
3: 小三角形A   [[0,0],[2,0],[1,1]]              面積=1  直角二等辺三角形(直角at(1,1))
4: 小三角形B   [[0,0],[2,0],[1,1]]              面積=1  直角二等辺三角形(直角at(1,1))
5: 正方形      [[0,0],[1,-1],[2,0],[1,1]]        面積=2  辺=√2, 45度傾き
6: 平行四辺形  [[0,0],[2,0],[3,1],[1,1]]         面積=2  底辺=2, 高さ=1
```

合計面積 = 4+4+2+1+1+2+2 = 16（4×4の正方形に相当）

面積比 = 4:4:2:1:1:2:2

## パズルデータ形式

```javascript
{
  id: "Q1",
  difficulty: 1,              // 1-5
  title: "パズル名",
  silhouette: [               // シルエット多角形（複数ポリゴン可）
    [[x1,y1],[x2,y2],[x3,y3],...]
  ],
  answer: [                   // 7ピースの正解配置
    { piece: 0, x: 0, y: 0, rotation: 0, flip: false },
    { piece: 1, x: 0, y: 0, rotation: 0, flip: false },
    { piece: 2, x: 0, y: 0, rotation: 0, flip: false },
    { piece: 3, x: 0, y: 0, rotation: 0, flip: false },
    { piece: 4, x: 0, y: 0, rotation: 0, flip: false },
    { piece: 5, x: 0, y: 0, rotation: 0, flip: false },
    { piece: 6, x: 0, y: 0, rotation: 0, flip: false },
  ],
  hints: [0, 1],              // 最初から配置済みのピースインデックス
  hint: "ヒント文"
}
```

### フィールド説明

- `silhouette`: 完成形の外形。穴がある図形は複数ポリゴンで表現可能
- `answer[i].piece`: ピースタイプ（0-6、上記定義に対応）。必ず0-6を各1つ使う
- `answer[i].x, y`: ピースの基準点の移動量（単位座標系）
- `answer[i].rotation`: 回転角度（度、45度単位推奨）
- `answer[i].flip`: X軸反転するか
- `hints`: answer配列のインデックス。多いほど簡単
  - 3-4個 → ★（やさしい）
  - 1-2個 → ★★★（ふつう）
  - 0個 → ★★★★★（むずかしい）

### ピース変換の計算順序

1. 基本形状の頂点を取得
2. 重心を中心に反転（flipがtrueの場合、X座標を反転）
3. 重心を中心に回転（rotation度）
4. (x, y)だけ平行移動

### 座標設計のコツ

- グリッド上に配置するため、x/yは0.25単位が望ましい
- 回転は45度単位を推奨（0, 45, 90, 135, 180, 225, 270, 315）
- シルエットの頂点座標は整数または0.5単位が見やすい
- 全ピースの変換後の面積合計 = シルエットの面積になるよう設計する

## 難易度別20問セット

### ★ やさしい（ヒント3-4個）

Q1〜Q5: 基本的な幾何学図形（正方形、三角形、長方形、台形、平行四辺形）

### ★★★ ふつう（ヒント1-2個）

Q6〜Q13: 動物や身近なもののシルエット（ネコ、鳥、家、ロケット、魚、船、ハート、矢印）

### ★★★★★ むずかしい（ヒントなし）

Q14〜Q20: 複雑な形（走る人、白鳥、キツネ、花、風車、ダイヤモンド、数字）

## 検証チェックリスト

各問題について以下を確認:
- [ ] answer配列に7ピース（タイプ0-6が各1つ）含まれるか
- [ ] 各ピースの変換後面積が元の面積と一致するか
- [ ] シルエット面積とピース合計面積が一致するか
- [ ] ピース同士が重なっていないか
- [ ] hints配列のインデックスが0-6の範囲内か
- [ ] 回転角度が45度の倍数か
- [ ] 難易度がヒント数と整合しているか

## 検証方法

```bash
python3 scripts/validate_tangram.py <生成したHTMLファイル>
```
