# タングラムパズル

標準7ピースをドラッグ＆ドロップで配置し、お手本のシルエットを完成させるHTML教材を生成する。

## ゲーム概要

- 7つのピース（大三角形×2、中三角形、小三角形×2、正方形、平行四辺形）を使用
- お手本のシルエットと同じ形になるようにピースを配置する
- クリックで選択 → 回転・反転ボタンで操作 → ドラッグで移動
- ヒントピースは最初から正解位置に薄く表示
- 全ピースが正解位置に揃うとクリア → 次の問題へ自動遷移

## ワークフロー

### 1. テンプレートをコピー

[assets/template.html](assets/template.html) を出力先にコピーする。

### 2. PUZZLES配列を編集

テンプレート内の `const PUZZLES = [...]` にパズルデータを挿入する。
パズルデータの詳細は [references/puzzles.md](references/puzzles.md) を参照。

```javascript
{ id: "Q1", difficulty: 1, title: "正方形をつくろう",
  silhouette: [[[0,0],[4,0],[4,4],[0,4]]],
  answer: [
    { piece: 0, x: 0, y: 0, rotation: 0, flip: false },
    { piece: 1, x: 2, y: 2, rotation: 180, flip: false },
    { piece: 2, x: 2, y: 0, rotation: 135, flip: false },
    { piece: 3, x: 0, y: 2, rotation: -90, flip: false },
    { piece: 4, x: 3, y: 1, rotation: 90, flip: false },
    { piece: 5, x: 1.5, y: 2.5, rotation: 45, flip: false },
    { piece: 6, x: 2, y: 2, rotation: 0, flip: false },
  ],
  hints: [0, 1],
  hint: "大きい三角形を対角に置いてみよう" },
```

- `silhouette`: 完成形の外形ポリゴン（複数ポリゴン可）
- `answer[i].piece`: ピースタイプ（0-6）。必ず0-6を各1つ使う
- `answer[i].x, y`: ピースの移動量
- `answer[i].rotation`: 回転角度（度、45度単位推奨）
- `answer[i].flip`: X軸反転するか
- `hints`: 最初から配置済みのピースのインデックス（answer配列のインデックス）

### 3. 難易度の選び方

| 対象 | ヒント数 | 難易度 |
|---|---|---|
| 中学年 | 3-4個 | ★ |
| 高学年（初級） | 1-2個 | ★★★ |
| 高学年（上級） | 0個 | ★★★★★ |

5〜20問を段階的に出題するのが効果的。

### 4. 検証

パズルデータを挿入した後、検証スクリプトで確認する:

```bash
python3 scripts/validate_tangram.py <生成したHTMLファイル>
```

検証項目:
- 7ピース（タイプ0-6）が各1つ含まれるか
- 各ピースの変換後面積が正しいか
- シルエット面積とピース合計面積が一致するか
- ピース同士の重なりがないか
- ヒントインデックスが有効範囲内か

### 5. 出力

HTMLファイルのパスを伝え、ブラウザで開くよう案内する。
