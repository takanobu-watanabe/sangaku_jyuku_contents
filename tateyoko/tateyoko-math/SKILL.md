# Tateyoko Math（たてよこ算）

## Overview

小学生向けの「たてよこ算」インタラクティブHTML教材を生成する。グリッドに数字を配置し、各行・各列の計算結果が目標値と一致するようにするパズル。

## パズルのルール

### 基本構造
- グリッドの左上に演算子（＋ or ×）
- 1行目（左上を除く）に各列の目標値
- 1列目（左上を除く）に各行の目標値
- 内側のセルに数字を配置して、各行・各列の計算結果が目標値と一致するようにする

### 足し算版（＋）
- 各行の内側セルの合計 = その行の目標値（左端）
- 各列の内側セルの合計 = その列の目標値（上端）

### 掛け算版（×）
- 各行の内側セルの積 = その行の目標値（左端）
- 各列の内側セルの積 = その列の目標値（上端）

### 制約
- 同じ行・同じ列に同じ数字を使ってはいけない
- 使用する数字は1〜9の範囲

### 黒マス
- 3×3以上のグリッドでは一部のセルを「黒マス」として使用不可にできる
- 黒マスは計算から除外される
- 難易度調整に使用

## サイズバリエーション

- **2×2内部グリッド**: 3行3列（目標値含む）。入門〜基本レベル
- **3×3内部グリッド**: 4行4列（目標値含む）。黒マスありの問題も含む。応用レベル

## 問題生成

scripts/generate_tateyoko.py を使用して問題を生成・検証する。

```bash
# 2×2足し算20問 + 掛け算10問を生成
python3 scripts/generate_tateyoko.py --size 2 --add 20 --mul 10 --output tateyoko_2x2.html

# 3×3足し算＋掛け算を生成
python3 scripts/generate_tateyoko.py --size 3 --add 10 --mul 5 --output tateyoko_3x3.html

# 検証のみ
python3 scripts/generate_tateyoko.py --verify tateyoko_2x2.html
```

## インタラクティブ機能

HTML教材には以下の機能を含める：

- 数字のクリック入力（1〜9）
- 行・列の合計/積の自動計算表示
- 正解チェック機能
- ヒント表示
- リセット機能
- 問題切り替え（前へ/次へ）
